# 여덟 글자 — AI 사주 웹앱 (2차 완성본)

모바일 우선 정적 사이트. 빌드 과정 없이 `saju-site/` 폴더를 그대로 올리면 동작해요.

```js
product: {

  listPrice: 9900,      // 정가 (할인율·취소선 자동 계산)
  priceTag: '런칭 특가',
  priceNote: '런칭 특가 · 평생 소장',
  focusYear: 2027       // 리포트의 월별 흐름 기준 연도
},
payment: {
  bank: '카카오뱅크',
  account: '000-0000-0000',   // ← 실제 계좌
  holder: '예금주',            // ← 예금주
  placeholder: true            // ← 실제 계좌 넣으면 false (테스트용 표시가 사라짐)
},
payappPaymentUrl: '',     // ← 페이앱 결제 링크. 넣으면 모달 주 버튼이 '페이앱으로 결제하기'로 바뀜
openChat: {
  url: '',                // ← https://open.kakao.com/o/.... 넣으면 버튼이 실제 링크로 연결
  label: '오픈채팅으로 신청하기'
},
unlock: {
  codes: ['TEST3900'],    // ← 실사용 해금 코드 추가
```

취소선 가격과 할인율이 같이 바뀝니다.

## 2. 결제·해금 흐름

1. 무료 결과 하단 잠금 카드 → **상세 리포트 받기 · 런칭 특가 3,900원**
2. 모달에서 신청 (페이앱 링크가 있으면 페이앱 / 없으면 계좌이체 + 오픈채팅)
3. 결제 후 받은 **해금 코드**를 모달의 `이미 결제했어요 · 해금 코드 입력`에 넣음
4. 리포트가 바로 열리고, 상단 `PDF · 인쇄`로 저장

| 경로 | 동작 |
| --- | --- |
| `?code=TEST3900` | 코드로 열기 (검수용) |
| `?unlocked=1` | 결제 후 복귀 훅 — 저장된 사주가 있으면 리포트가 자동으로 열림 |
| `?payapp=success` | 위와 동일 (페이앱 복귀 주소에 붙이면 됨) |
| `?token=...` | `unlock.tokens`에 등록한 토큰만 통과 |

해금 상태는 브라우저 `localStorage`(`saju:unlock:v1`)에 남아서, 같은 기기에서는
다시 열어도 코드 없이 리포트가 열립니다. **테스트: 다시 잠그기** 버튼으로 초기화할 수 있어요.

> ⚠️ 정적 사이트라서 코드 검사도 브라우저 안에서만 이뤄집니다. 결제 사실을 서버에서
> 확인하는 구조가 아니라, 지금은 "정직한 고객이 코드만 넣으면 열린다" 수준이에요.
> 실제 판매량이 붙으면 결제 웹훅 → 코드 발급을 서버에서 처리하는 방식으로 바꾸는 게 맞습니다.

## 3. 유료 리포트에 들어가는 것

`js/report.js`가 엔진이 계산한 값으로만 본문을 만듭니다. 연도·나이를 미리 박아 넣은 문구는 없어요.

1. **한 장 요약** — 일간, 중심 십성, 강한/빈 오행, 신강·신약 점수(참고 지표)
2. **10년 대운 흐름표** — 8개 대운의 나이·연도·간지·십성, 지금 구간 표시,
   현재 대운의 일·돈·관계 풀이, 대운 지지가 원국과 충·형·파·해·육합하는 지점
3. **평생 재물운** — 재성 개수·자리·뿌리, 재고(財庫)가 열렸는지, 식상→재성 구조,
   돈이 모이는 지점 / 새는 지점, 앞으로 10년 중 돈이 트이는 해와 이유
4. **연애·인연** — 배우자성(여:관성/남:재성)의 자리, 일지와 원국의 관계,
   잘 맞는 상대의 일지·일간(육합·삼합·정관·정인), 피해야 할 상대(충·상관·편관),
   천을귀인 위치 또는 귀인이 들어오는 해, 2027년에 인연이 붙는 달
5. **2027 정미년** — 세운 요약, 분기(인묘진/사오미/신유술/해자축) 흐름,
   열두 절기월 상세(절입일·간지·십성·원국과의 관계·주의점), 주의할 달, 돈이 움직이는 달
6. **개운 전략** — 부족한 오행의 색·소재·자리·습관, 덜어낼 것, 지금 대운에 맞는 선택
7. **계산 기준** — 절입·음양력·대운수·신강약 기준과 면책

인쇄(PDF)는 A4 기준 8~9장으로 떨어집니다. `@media print`에서 밝은 글자를 어두운 색으로
바꾸고, 표·카드가 페이지 중간에서 잘리지 않게 잡아뒀어요.

## 4. 페이앱 연동 메모

`payappPaymentUrl`에 결제 링크를 넣으면:
- 모달의 주 버튼이 **페이앱으로 결제하기**(새 창)로 바뀌고 계좌 안내는 숨겨집니다.
- 신청 절차 문구도 페이앱 기준으로 바뀝니다.
- 결제 완료 후 돌아올 주소를 `https://내주소/?payapp=success` 로 지정하면,
  돌아오자마자 리포트가 열립니다.

페이앱 개인 가입 계정에서 결제 링크(또는 결제 요청 URL)를 만들고, 결제 완료 시
리다이렉트 주소를 위 형태로 넣으면 됩니다. 페이앱이 결제 건마다 토큰을 돌려준다면
`unlock.tokens`에 넣거나, 서버 없이 쓰려면 `?unlocked=1` 복귀 방식을 권합니다
(토큰을 브라우저에서 검증하는 건 위조가 가능하다는 점은 같습니다).

## 5. 검증

```bash

node test/crosscheck.js     # 1,444 / 1,444 일치
node test/report.test.js    # 사주 56건 × 35항목 통과
```

`report.test.js`가 확인하는 것
- 무작위 56개 사주(시간 모름·음력 윤달·1900년·2050년 포함)에서 리포트가 예외 없이 생성됨
- 대운이 10년 간격으로 이어지고, 순행/역행 방향과 간지 진행이 맞음
- 2027년 열두 달이 절입일로 정확히 끊기고, 월간(오호둔)이 맞음
- 월별 충·형·파·해·육합이 원국 지지와 일치함
- `3월 하순`·`31세`·`○○` 같은 계산 무관 예시 문구가 남아 있지 않음
- 이름에 HTML을 넣어도 이스케이프됨

스크린샷·PDF 재생성:

## 6. 계산 기준 (사이트 하단·리포트에도 표기)

| 항목 | 기준 |
| --- | --- |
| 년주 | 입춘 절입시각 |
| 월주 | 12절(소한·입춘·경칩·청명·입하·망종·소서·입추·백로·한로·입동·대설) 절입시각 |
| 일주 | 율리우스적일 60갑자 순환 |
| 시주 | 12지시, 시두법(일간 기준) |
| 자시 | 야자시 기준 — 23시대는 일주를 그날로 두고 시주만 다음 날 일간으로 |
| 대운 | 월주에서 순행/역행, 3일=1년 환산 |
| 신강·신약 | 월령 장악 + 통근 + 천간 생조를 점수화한 참고 지표(전통 간명의 축약식) |
| 시간대 | 한국표준시(KST) 그대로. 경도 보정·서머타임 미적용 |
| 지원 범위 | 1900~2050년 |

경도 보정(서울 −32분)이나 진태양시까지 반영하려면 `saju-engine.js`의 `compute()`에
출생지 경도 인자를 추가하면 됩니다. 앱마다 결과가 갈리는 지점이라, 옵션으로 열 때는
기준을 함께 밝히는 게 좋아요.

## 7. 배포

정적 호스팅이면 어디든 됩니다 (빌드 없음).

- **GitHub Pages**: 저장소에 `saju-site/`를 올리고 Settings → Pages에서 폴더(or Actions) 지정
- **Netlify / Cloudflare Pages**: 폴더 드래그 또는 `netlify deploy --prod --dir saju-site`
- **Vercel**: `vercel --prod saju-site`

배포 후 할 일
- OG 이미지(1200×630) 추가 — 지금은 텍스트 메타만 있음
- 페이앱 링크·계좌·오픈채팅 링크를 `config.js`에 실제 값으로 교체
- `unlock.sampleEnabled: false` (샘플 버튼과 '다시 잠그기' 숨김)
- 개인정보처리방침 페이지, 사업자(통신판매업) 신고

## 8. 남은 작업

- **경도 보정 옵션** — 출생지 입력 → 진태양시 보정 (앱 간 결과 차이의 주 원인)
- **결제 자동화** — 페이앱 웹훅 → 코드 발급 → 메일 발송 (서버 필요)
- **결과 이미지 저장** — 캔버스 렌더로 카톡 공유용 카드
- **제휴 슬롯** — 개운 아이템 카드의 `data-affiliate="coupang" data-slot="금"`에 추적 링크 연결
- **리포트 문장 확장** — 지금은 십성·관계 규칙 기반. 상담가 검수를 거친 문장을 더하면 깊어짐
